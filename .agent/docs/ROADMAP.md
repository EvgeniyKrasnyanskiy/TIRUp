## 🚀 Приоритет 2 (Среднесрочные задачи)

### 2.1. Поддержка носимых устройств (Wear OS & Smartwatch Integration)
- **Суть**: Мгновенный доступ к сахару, стрелке тренда, времени замера и статусу IoB на смарт-часах без необходимости доставать телефон.
- **Архитектурное решение**:
  - **Модуль Wear OS Companion / Tiles**: Виджет-плитка для часов (Wear OS 3+) и циферблатные усложнения (Complications).
  - **Локальный микро-HTTP сервер для часов Garmin / Amazfit / Pebble**: REST-эндпоинт на localhost (порт 17581) в формате JSON для интеграции со сторонними циферблатами.

## 🔮 Приоритет 3 (Стратегическое развитие)

### 3.1. Семейный мониторинг и синхронизация квитирования тревог (Family Alert Sync)
- **Суть**: При наблюдении за пациентом несколькими родственниками отключение тревоги одним из них автоматически отключает сирену у остальных.
- **Архитектурное решение**:
  - Лёгкий протокол взаимного квитирования по локальной сети Wi-Fi/LAN или через push-сигнал Nightscout.
  - Логирование: отображение, кто именно из наблюдателей подтвердил и отключил тревогу.

### 3.2. Автоматическое зашифрованное резервное копирование в облако (Cloud Backup)
- **Суть**: Защита от потери многолетней медицинской истории при смене или поломке смартфона.
- **Архитектурное решение**:
  - Автобэкап по расписанию (раз в неделю) в Google Drive / Nextcloud / WebDAV.
  - Сквозное AES-256 GCM шифрование мастер-паролем пользователя перед отправкой файла.
