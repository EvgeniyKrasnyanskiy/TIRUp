# Дорожная карта развития TIRUp (Roadmap)

## 1. Роли и терминология: «Мастер» и «Фоловер» [Выполнено]
- [x] **Мягкая терминология**: Замена формулировок «Пациент / Опекун» на привычные в диа-сообществе **«Мастер»** (владелец сенсора / ведущий) и **«Фоловер»** (наблюдатель / ведомый).
- [x] **Расположение в настройках**: Вынос переключателя роли в верхнюю часть раздела настроек («Роль устройства: 👑 Мастер / 👁️ Фоловер»), сразу под блоком «Мой профиль».
- [x] **Разделение тестирования тревог**:
  - Для **Мастера**: тест критической тревоги запускает экран спасения при гипо (`PatientCriticalHypoActivity`: прием быстрых углеводов, таймер купирования, экстренный контакт).
  - Для **Фоловера**: тест критической тревоги запускает экран тревоги опекуна/фоловера (`CaregiverSosActivity`: карточка подопечного, уровень сахара, тренд, задержка ответа, кнопка быстрого звонка и ссылка на карту).

---

## 2. Экстренные и важные сообщения поверх всех окон (HUD Heads-Up) [Выполнено]
- [x] **Heads-Up оверлей для сообщений Мастер ⇄ Фоловер**:
  - При получении важного SMS (например, «Выпей сок!», «Подколи 1 ед», «Углеводы приняты, сахар поднимается»):
  - Автоматическое пробуждение экрана устройства на 15 секунд (`SCREEN_BRIGHT_WAKE_LOCK` + `ACQUIRE_CAUSES_WAKEUP`).
  - Отображение крупного контрастного сообщения поверх всех окон и экрана блокировки с плавно пульсирующей неоновой каймой.
  - Мягкая ненавязчивая тактильная вибрация (без включения тревожной сирены).
  - Крупная зеленая кнопка «ОК!» (закрыть) и кнопка «Ответить» (диалог быстрого ответа со строгим лимитом 70 символов и готовыми чипами-шаблонами).
  - Инструмент проверки в настройках («Тест важного сообщения (Heads-Up)»).

---

## 3. Звуковое оформление тревог (Кастомные звуки / GDH)
- [ ] **Поддержка мелодичных тревог GDH**:
  - Оптимизация и интеграция компактных OGG-аудиодорожек (моно, 80–96 kbps, размер 20–40 КБ на звук) для тревог высокого и низкого уровня.
  - Воспроизведение через аудиопоток `USAGE_ALARM` с сохранением надежности пробивания режима «Не беспокоить» (DND).
  - Выбор стиля звуков в настройках: «Синтезированные медицинские тоны» vs «Мелодии GDH».
