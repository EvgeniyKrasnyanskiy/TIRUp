## 2. Прямой приём от xDrip+ по Wi-Fi (LAN Follower) и симметричный ряд индикаторов статуса
- [ ] **Сетевой клиент прямого приёма от xDrip+ по Wi-Fi**:
  - Подключение к локальному веб-серверу xDrip+ на телефоне мастера (`http://<master_ip>:17580`) с аутентификацией по `API Secret` (по образцу архитектуры `DiaNight`).
  - Опрос `sgv.json` (сахар, тренд), `pebble` (активный инсулин IoB, активные углеводы CoB) и `treatments.json` (болюсы, еда).
  - Работа без доступа в интернет (в домашней Wi-Fi сети или через точку доступа Hotspot мастера).
- [ ] **Автоматическое обнаружение мастера в подсети**:
  - Быстрое фоновое сканирование адресов `192.168.x.1`–`254` пулом параллельных корутин на порт 17580 с таймаутом 1.2 с при смене IP или потере связи.
  - **Защита батареи**: сканирование блокируется (no-op), если устройство не подключено к сети Wi-Fi или Hotspot.
  - Автоматическое возобновление связи при возвращении устройства в Wi-Fi сеть (`NetworkCallback`).
  - Кнопка ручного запуска «🔍 Найти мастера» в настройках.
- [ ] **Сквозная дедупликация данных**:
  - Единая точка сохранения в Room DB с проверкой `timestamp` (высший приоритет: локальный xDrip → BLE Bridge → Wi-Fi LAN → Nightscout Cloud).
- [ ] **Симметричный ряд индикаторов статуса на главном экране (HeroGlucoseCard)**:
  - Единая сбалансированная горизонтальная строка слева направо:
    `[Уведомления/колокольчик]` → `[Wi-Fi LAN]` → `[Батарея мастера 🔋 %]` → `[IoB 💉]` → `[CoB 🍞]` → `[BLE радиомост 📡/📻]` → `[AoD 🌙]`.
  - **Гарантированная адаптивность**: динамические отступы, компактный формат чипов и автоподгонка размера, чтобы все элементы гарантированно умещались в одну строку без обрезания и переноса на любых экранах (включая узкие устройства).
  - Интерактивный тап по пиктограмме Wi-Fi: всплывающая карточка со статусом связи, текущим IP мастера и кнопкой быстрого поиска.
