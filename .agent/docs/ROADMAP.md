# Дорожная карта проекта TIRUp (Roadmap)

В данный документ вынесены задачи для следующего этапа разработки после завершения полевого тестирования стабильности и сбора обратной связи.

---

## Задачи на следующий этап

### 1. Подготовка презентационного поста для Telegram-канала
- Составление структурированного, понятного и привлекательного текста описания приложения TIRUp для сообщества людей с диабетом.
- Ключевые акценты: надежность получения данных из xDrip+/BLE, умные ночные профили, упреждающие тревоги, 25-минутная линия прогноза без необходимости подсчета ФЧИ/УК, Семейный BLE-мост без интернета, журнал HbA1c и GMI, Zero-Lag годовые архивы, независимость и энергоэффективность.

### 2. Сравнение дней недели в аналитических отчетах (Низкий приоритет)
- Добавление в раздел «Отчеты» сравнительной аналитики по дням недели (например, пн–пт vs сб–вс).
- Автоматическое выявление скрытых паттернов вариабельности (оценка стабильности гликемии в рабочие дни по сравнению с выходными, влияние изменения режима дня).

### 3. Наполнение 5-го столбца виджета 5х1
- Проблема: при отсутствии активного инсулина (IoB = 0) и батареи мастера (не в режиме Observer BLE-моста) 5-й столбец скрывается, оставляя свободное место в правой части виджета.
- Задача: сделать 5-й столбец всегда заполненным и полезным:
  - Выбор между клиническими метриками (TBR % гипогликемии + eA1c / GMI) или оперативными (время замера + 15-минутный прогноз сахара / активные углеводы CoB).
  - Реализация умного fallback: если есть батарея мастера — отображать Батарею и Время замера; если батареи нет — выводить TBR и eA1c.
