# Дорожная карта проекта TIRUp (Roadmap)

В данный документ вынесены задачи для следующего этапа разработки после завершения полевого тестирования стабильности и сбора обратной связи.

---

## Задачи на следующий этап

### 1. Гарантированная сохранность локальной БД и перенос данных на новый телефон (Zero-Data-Loss & Migration)
- **Гарантированная сохранность локальной БД (Zero-Data-Loss Architecture)**:
  - Полная изоляция истории замеров (`GlucoseReadingEntity`) и меток (`TreatmentEntity`) внутри базы данных Room приложения TIRUp, независимая от сбоев, очистки кэша или переустановок xDrip+.
  - Автоматический тихий ежедневный фоновый снапшот БД (SQLite / JSON) в общедоступную системную папку `Documents/TIRUp/Backups/` (не удаляется при удалении или обновлении приложения Android).
  - Опциональная фоновая репликация в защищенный личный Google Drive пользователя без необходимости развертывания сторонних веб-серверов или баз данных MongoDB.
- **Мастер переноса на новый смартфон без интернета (Direct Device-to-Device Sync)**:
  - Экспорт и импорт полного профиля: все локальные настройки, пороги тревог, профили сна, параметры сенсоров, калибровки, замеры, болюсы, углеводы и счетчики расходников.
  - Мгновенный перенос всей накопленной истории и настроек при смене смартфона за 10–15 секунд.
  - Прямое соединение «телефон-в-телефон» по локальному Wi-Fi / Wi-Fi Direct или через защищенный зашифрованный файл архива (JSON / ZIP).

### 2. Подготовка презентационного поста для Telegram-канала
- Составление структурированного, понятного и привлекательного текста описания приложения TIRUp для сообщества людей с диабетом.
- Ключевые акценты: надежность получения данных из xDrip+/BLE, умные ночные профили, упреждающие тревоги, 25-минутная линия прогноза без необходимости подсчета ФЧИ/УК, независимость и энергоэффективность.

### 3. Сравнение дней недели в аналитических отчетах (Низкий приоритет)
- Добавление в раздел «Отчеты» сравнительной аналитики по дням недели (например, пн–пт vs сб–вс).
- Автоматическое выявление скрытых паттернов вариабельности (оценка стабильности гликемии в рабочие дни по сравнению с выходными, влияние изменения режима дня).
