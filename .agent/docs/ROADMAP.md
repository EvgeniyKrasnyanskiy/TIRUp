## 🎯 Приоритет 1 (Ближайший релиз)

### 1.1. Публикация нового релиза TIRUp и формирование полного описания нововведений (Release Notes)
- **Суть**: Подготовка и публикация обновлённого релиза с систематизацией всех реализованных функций и обновлением сопутствующей документации.
- **Состав нововведений для включения в описание релиза**:
  - **Дневник терапии и оверлей на графике**: Быстрый ввод болюсов 💉, углеводов/ХЕ 🍞, замеров глюкометра 🩸 и заметок 💬; интерактивные маркеры с проекционными линиями на 24-часовом графике Canvas; удаление с постоянными UUID и синхронизация с Nightscout API.
  - **Система предиктивных и скоростных тревог**: Упреждающие тревоги с горизонтом 15–30 мин; скоростные тревоги падения/роста ($\ge 0.11$ ммоль/л/мин); калиброванные MP3-семплы с унифицированным аудиопревью в настройках без засорения системной шторки; уточнённая длительность тревог (~60с для крит. гипо, ~35с для крит. гипер, ~15с для затяжных, ~3с для основных и скоростных).
  - **Семейный BLE-мост (LE Coded PHY)**: Настраиваемый эко-режим приёмника (1 час тишины); мгновенное самовосстановление (Self-Healing) в `LOW_LATENCY`; контурная световая анимация поиска с обратным отсчётом (60 сек); метрики качества радиоканала (PDR % и RSSI dBm).
  - **Интерактивные виджеты нового поколения (Jetpack Glance)**: 5 форматов виджетов (5x1, 4x2, 3x2, 2x2, 1x2); мгновенный снуз сирен в 1 тап; плавная настройка прозрачности фона (0%..100%).
  - **Улучшения SMS-телеметрии**: Полная поддержка кодировки GSM 7-bit с транслитерацией кириллицы; хронологический тренд `[5.2 > 5.5 > 5.7]`; вывод уровня заряда аккумулятора и активных углеводов (CoB).
  - **Учёт расходных материалов**: Отслеживание дат замены сенсора, канюли и ланцета; интеллектуальное автопродление и подтверждение перезапуска по заметкам xDrip+.
  - **Автобэкап и Zero-Lag архивация**: Ежедневное резервное копирование в 23:59:59 без специальных разрешений; ручной экспорт в ZIP; ежегодная архивация CSV для максимального быстродействия БД.
- **Шаги выполнения**:
  1. Синхронизация версий в `app/build.gradle.kts`.
  2. Финализация `CHANGELOG.md` на русском и английском языках.
  3. Прогон набора unit-тестов (`./gradlew testDebugUnitTest`).
  4. Сборка релизного APK (`./gradlew assembleRelease` / `assembleDebug`).
  5. Подготовка шаблона публикации релиза на GitHub.

## 🚀 Приоритет 2 (Среднесрочные задачи)

### 2.1. Поддержка носимых устройств (Wear OS & Smartwatch Integration)
- **Суть**: Мгновенный доступ к сахару, стрелке тренда, времени замера и статусу IoB на смарт-часах без необходимости доставать телефон.
- **Архитектурное решение**:
  - **Модуль Wear OS Companion / Tiles**: Виджет-плитка для часов (Wear OS 3+) и циферблатные усложнения (Complications).
  - **Локальный микро-HTTP сервер для часов Garmin / Amazfit / Pebble**: REST-эндпоинт на localhost (порт 17581) в формате JSON для интеграции со сторонними циферблатами.

## 🔮 Приоритет 3 (Стратегическое развитие)

### 3.1. Семейный мониторинг и синхронизация квитирования тревог (Family Alert Sync)
- **Суть**: При наблюдении за пациентом несколькими родственниками отключение тревоги одним из них автоматически отключает сирену у остальных.
- **Архитектурное решение**:
  - Лёгкий протокол взаимного квитирования по локальной сети Wi-Fi/LAN или через push-сигнал Nightscout.
  - Логирование: отображение, кто именно из наблюдателей подтвердил и отключил тревогу.

### 3.2. Автоматическое зашифрованное резервное копирование в облако (Cloud Backup)
- **Суть**: Защита от потери многолетней медицинской истории при смене или поломке смартфона.
- **Архитектурное решение**:
  - Автобэкап по расписанию (раз в неделю) в Google Drive / Nextcloud / WebDAV.
  - Сквозное AES-256 GCM шифрование мастер-паролем пользователя перед отправкой файла.
