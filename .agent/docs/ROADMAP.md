# Дорожная карта проекта TIRUp (Roadmap)

В данный документ вынесены задачи для следующего этапа разработки после завершения полевого тестирования стабильности и сбора обратной связи.

---

## Задачи на следующий этап

### 1. Резервное копирование и перенос данных (Backup & Restore)
- Экспорт всех локальных настроек, порогов тревог, профилей сна, параметров сенсоров и калибровок в единый зашифрованный файл (JSON / ZIP).
- Удобный импорт конфигурации на новый смартфон в один клик без необходимости повторной ручной настройки всех параметров.

### 2. Сравнение дней недели в аналитических отчетах
- Добавление в раздел «Отчеты» сравнительной аналитики по дням недели (например, пн–пт vs сб–вс).
- Автоматическое выявление скрытых паттернов вариабельности (оценка стабильности гликемии в рабочие дни по сравнению с выходными, влияние изменения режима дня).

### 3. Предпросмотр виджетов (Widget Previews) при добавлении на рабочий стол
- Генерация и подключение статических графических превью (`previewImage` / `previewLayout`) в конфигурации `AppWidgetProviderInfo`.
- Устранение отображения дефолтной системной иконки приложения в лаунчере при выборе виджетов рабочего стола, отображение реалистичного макета виджета в каталоге.

### 4. Подготовка презентационного поста для Telegram-канала
- Составление структурированного, понятного и привлекательного текста описания приложения TIRUp для сообщества людей с диабетом.
- Ключевые акценты: надежность получения данных из xDrip+/BLE, умные ночные профили, упреждающие тревоги, 25-минутная линия прогноза без необходимости подсчета ФЧИ/УК, независимость и энергоэффективность.

### 5. Подумать на счёт уведомлений о том когда инсулин введён но через 45 минут стрелка глюкоза не начала падать. значит нужно добавить болюса. или ещё что то сделать нужно даже в ночное время? 

### 6. Автономный локальный Nightscout (Local Nightscout & P2P-перенос данных без интернета)
- **Гарантированная сохранность локальной БД (Zero-Data-Loss Architecture)**:
  - Полная изоляция истории замеров (`GlucoseReadingEntity`) и меток (`TreatmentEntity`) внутри базы данных Room приложения TIRUp, независимая от сбоев, очистки кэша или переустановок xDrip+.
  - Автоматический тихий ежедневный фоновый снапшот БД (SQLite / JSON) в общедоступную системную папку `Documents/TIRUp/Backups/` (не удаляется при удалении или обновлении приложения Android).
  - Опциональная фоновая репликация в защищенный личный Google Drive пользователя без необходимости развертывания веб-серверов или баз данных MongoDB.
- **P2P-перенос на новый телефон без интернета (Direct Device-to-Device Sync)**:
  - Мгновенный перенос всей накопленной истории (замеры, болюсы, углеводы, калибровки, профили сна, счетчики расходников) при смене смартфона за 10–15 секунд.
  - Прямое соединение «телефон-в-телефон» по локальному Wi-Fi / Wi-Fi Direct или через защищенный QR-код без использования сторонних облачных серверов.
- **Встроенный локальный HTTP/REST сервер (Local Nightscout API Server)**:
  - Встраиваемый легковесный HTTP-сервер прямо в Android-службу TIRUp (локальный порт `:17580`).
  - Полная совместимость со стандартными эндпоинтами Nightscout API (`/api/v1/entries.json`, `/api/v1/status.json`).
  - Прямая трансляция данных на смарт-часы (Garmin, Amazfit, Apple Watch), прикроватные домашние планшеты-мониторы и виджеты в домашней Wi-Fi сети полностью автономно, без интернета и без риска падения внешних серверов.
- **Независимый прямой приёмник BLE-сенсоров**:
  - Дальнейшее развитие собственного BLE-стека TIRUp для прямого подключения к сенсорам CGM (Sibionics, Libre, Dexcom, Medtrum) в качестве автономного первичного источника данных.
