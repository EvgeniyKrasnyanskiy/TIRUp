# Запланированные задачи для будущей реализации

## 1. Отображение точек/маркеров IoB и CoB на суточном графике глюкозы (DailyGlucoseChart)
### Контекст:
Ранее в истории репозитория (коммиты c15bea0 и cdce587) реализовывалось отображение маркеров болюсов инсулина и приемов углеводов (treatments) на 24-часовом графике глюкозы.

### Требования к реализации:
1. **Синхронизация маркеров**:
   - При получении болюсов и углеводов (из broadcast xDrip+ или через опрос http://127.0.0.1:17580/treatments.json) сохранять их в таблицу treatments базы данных Room AppDatabase.
   - Загружать список treatments за текущие отображаемые сутки в DailyGlucoseChart.kt.
2. **Визуализация на графике**:
   - Отображать маркеры инсулина (синяя иконка шприца/капли с дозой, например 💉 4.5 Ед) на временной оси в момент введения.
   - Отображать маркеры углеводов (оранжевая иконка хлеба с граммами, например 🍞 25 г).
   - При наведении/клике на маркер показывать всплывающую подсказку (время, точная доза/вес углеводов, заметка к приёму пищи).
3. **Настройка видимости**:
   - Обеспечить работу переключателя в Настройках: «Отображать болюсы и углеводы на графике» (showTreatmentsOnChart).

## 2. Двусторонняя синхронизация удаления IoB и CoB (из xDrip+ и по нажатию на графике)
### Контекст:
Если пользователь удаляет ошибочно введённый болюс или приём углеводов в xDrip+, этот приём должен также автоматически исчезать из TIRUp. Кроме того, пользователь должен иметь возможность удалить ошибочную точку прямо в TIRUp по клику на неё на графике.

### Требования к реализации:
1. **Синхронизация удаления из xDrip+**:
   - При периодическом опросе http://127.0.0.1:17580/treatments.json или получении событий синхронизации сверять список активных записей за последние 24 часа.
   - Если запись с соответствующим таймстемпом/ID удалена в xDrip+, автоматически удалять её из локальной таблицы treatments в AppDatabase.
   - Пересчитывать текущие значения iob и cob для последнего замера глюкозы, исключая удалённый приём.
2. **Интерактивное удаление по клику на точку на графике**:
   - При нажатии пользователем на точку/маркер болюса или углеводов открывать диалог подтверждения: «Удалить запись о введении инсулина / углеводов?».
   - При подтверждении удалять запись из локальной БД treatmentDao().deleteTreatmentById(id) (через FocusViewModel.deleteTreatment(id)).
   - Если доступен API xDrip+ или Intent broadcast на удаление (com.eveningoutpost.dexdrip.TreatmentDelete), отправлять уведомление в xDrip+ для поддержания консистентности данных между обеими программами.
