# План реализации задач (График, Синхронизация, Уведомления, Отчёты, Настройки)

## 1. Статус выполнения задач

1. [Выполнено] **Компактный комментарий метки на суточном графике** (`DailyGlucoseChart.kt`):
   - Ограничение длины примечания `tr.notes` (не более 10–12 символов с троеточием `…`).
   - Использование `maxLines = 1`, `overflow = TextOverflow.Ellipsis`.
   - Размещение всех элементов (`время`, `доза/углеводы`, `комментарий`, `удалить 🗑`, `закрыть ✕`) в одну строку без переносов.

2. [Выполнено] **Окно сна в Ночном профиле и удаление кнопки очистки** (`SettingsScreen.kt`):
   - Добавление поясняющей подписи к «Ночной профиль (окно сна)»: «Приблизительные часы сна (с шагом в 1 час)».
   - Замена формата отображения с `23:00` на `23 ч` / `07 ч` в селекторах.
   - Удаление излишней кнопки «Очистить метки болюсов и еды» и диалога подтверждения (данные управляются штатным тумблером видимости и синхронизацией с источником).

3. [Выполнено] **Двусторонняя синхронизация удаления болюсов/еды** (`DexdripBroadcastReceiver.kt`):
   - При получении списка treatments из xDrip (`treatments.json`) за последние 24 часа определять удалённые в источнике записи и удалять их из локальной таблицы `TreatmentEntity`.
   - Немедленный пересчёт IoB/CoB.

4. [Выполнено] **Автоудаление устаревших уведомлений из шторки** (`GlucoseAlertManager.kt`, `StalenessAlarmReceiver.kt`):
   - Отменять `NOTIFICATION_ID_PREDICTIVE` («Прогноз: ГИПО/ГИПЕР»), когда уровень сахара вернулся в целевой диапазон (TIR/TING).
   - Отменять предиктивное уведомление, если прошло более 30 минут с момента его генерации или данные устарели (>15 мин).

5. [Выполнено] **Центральное всплывающее окно при ошибке импорта** (`ReportsScreen.kt`):
   - Если `importMessage` содержит ошибку импорта или отсутствие точек, отображать модальный `AlertDialog` по центру экрана с описанием ошибки и кнопкой «Понятно».
   - Окрашивание текста ошибки на карточке в `MaterialTheme.colorScheme.error`.
