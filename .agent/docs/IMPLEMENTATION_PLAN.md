# План реализации: Светлая/Тёмная тема оформления и кликабельный бейдж стрика

## 1. Поддержка тем (Dark / Light / System Auto)
- В `UserSettings.kt` добавить перечисление:
  ```kotlin
  enum class ThemeMode {
      DARK,
      LIGHT,
      SYSTEM
  }
  ```
- В `SettingsRepositoryImpl.kt` сохранять и считывать `themeMode`.
- В `SettingsViewModel.kt` добавить `setThemeMode(mode: ThemeMode)`.

## 2. Адаптивная цветовая палитра `Theme.kt`
- Создать светлую и тёмную схемы Material 3 + вспомогательные цвета для карточек (`Surface`, `SurfaceElevated`, `Border`, `TextPrimary`, `TextSecondary`, `TextMuted`).
- Обернуть `TIRUpTheme` с поддержкой динамического выбора темы.

## 3. Селектор темы в Настройках (`SettingsScreen.kt`)
- В секцию «Предпочтения» добавить селектор:
  - 🌙 Тёмная
  - ☀️ Светлая
  - ⚙️ Авто (Системная)

## 4. Кликабельный бейдж серии (Стрик) на Главном экране (`FocusScreen.kt`)
- Сделать `StreakBadge` кликабельным с красивой анимацией нажатия.
- По тапу открывать диалоговое окно с подробным объяснением:
  - Количество непрерывных дней в целевом диапазоне.
  - Клиническое значение непрерывного удержания TIR.
  - Советы по сохранению и продлению серии.
