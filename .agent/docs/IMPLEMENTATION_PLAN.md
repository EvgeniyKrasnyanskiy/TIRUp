## 4. Итерация 4: [Completed] Кластеризация меток инсулина/углеводов (≤5 мин) и эшелонирование («лесенка») на суточном графике

  - Создана модель `TreatmentCluster` и функция `clusterTreatments(treatments, isInsulin, thresholdMs = 5 мин)`.
  - Отметки одного типа с разницей ≤ 5 минут объединяются в один компактный бейдж вида `4+2U` / `20+15g` (или `12U (+)` / `65g (+)` при превышении 8 символов).

  - При визуальном перекрытии по горизонтали (при текущем зуме) метки автоматически разносятся по высоте:
    - Инсулин: Level 0 (`chartTop + 6f`), Level 1 (`chartTop + 30f`).
    - Углеводы: Level 0 (`chartBottom - 26f`), Level 1 (`chartBottom - 50f`).
  - Вертикальные пунктирные направляющие аккуратно связывают метки обоих уровней со шкалой графика.
- **4.3. Инспектор по тапу (нижняя плашка)**:
  - Интерактивный тап учитывает вертикальную полуплоскость (Y-preference) для точного выбора между инсулином и углеводами при их совпадении по времени.

  - **Выход из нормы (Mini 34dp -> Alarm 60dp)**: пружинящая анимация масштабирования с `OvershootInterpolator(1.25f)` (300 мс), кружок плавно «выпрыгивает» из мини-режима с привязкой точки масштабирования `pivotX` к прилегающему краю экрана.
