# Комплексный план: 8 доработок TIRUp (AoD, синхронизация после обрыва связи, автопродление сенсора, UI)

## Описание задачи
1. Время "только что" захардкожено только на русском языке в `AodScreen.kt`.
2. Отсутствует горизонтальная ориентация у режима Always on Display (AoD).
3. Размер текста сахара увеличить минимум на 25%.
4. Обеспечить смещение всех элементов AoD (часы, кнопка закрытия, подсказки) для предотвращения выгорания AMOLED-дисплея.
5. Для фонарика в AoD: двойной тап для включения и двойной тап для отключения. Увеличить яркость подсказки фонарика на ~30-50%.
6. После потери связи и восстановления TIRUp отображает старые данные серым цветом ("28 минут назад"), хотя xDrip в режиме фолловера актуальные данные показывает.
7. Иконку "месяц" (AoD) перенести в карточке FocusScreen прямо под пиктограмму BLE-моста в правом верхнем углу.
8. Для сенсора добавить автопродление срока службы через поиск заметки в xDrip ("продлен", "рестарт", "+N дней" и т.д.).

---

## Архитектура и изменения по компонентам

### 1. `AndroidManifest.xml`
- Снять ограничение `android:screenOrientation="portrait"` для `AodActivity`, заменив на `android:screenOrientation="unspecified"`, чтобы работал поворот экрана в альбомный режим.

### 2. `AodScreen.kt`
- Локализация: замена захардкоженного `"только что"` и `"$ageMins мин назад"` на `stringResource(R.string.just_now)` и `stringResource(R.string.minutes_ago, ageMins)`.
- Размер шрифта сахара: увеличение со `110.sp` до `140.sp` в портрете, адаптивный размер `120.sp` в ландшафте. Стрелка: с `52.sp` до `62.sp`.
- Защита от выгорания: добавление смещения джиттера для часов и кнопки закрытия вверху экрана; плавное автоскрытие нижней подсказки через 10 секунд.
- Фонарик:
  - В `detectTapGestures` оставить отключение только по `onDoubleTap` (одиночный тап при активном фонарике игнорируется).
  - Увеличить яркость текста подсказки с `0xFF333333` до `0xFF777777` (+35%).
  - Обновить подсказку оверлея на `💡 Фонарик (двойной тап для выключения)` с контрастным цветом.
- Адаптивная ландшафтная верстка: компактные вертикальные отступы при высоте экрана < 500dp.

### 3. `FocusScreen.kt`
- Перенос иконки "месяц" (переход в AoD) из нижнего ряда карточки `HeroGlucoseCard` в правый верхний угол — прямо под пиктограмму `BleBridgeBadge`.
- Увеличение шрифта сахара в карточке Hero с `54.sp` до `68.sp` (+26%).

### 4. `DexdripBroadcastReceiver.kt`
- **Синхронизация после обрыва связи (`syncFromLocalXdrip`)**:
  - Исправление выбора `readingToPersist`: выбирать кандидата с максимальным timestamp среди `latestReadingFromPebble` (только если он свежий) и `backfilledReadings.maxByOrNull { it.timestamp }`.
  - Проверка `isNewer` относительно `latestInDbBefore` (зафиксированного до пакетной вставки), чтобы гарантированно вызывался `persistAndDistributeReading`.
- **Автопродление и учет ланцета (`syncIobCobFromPebble`)**:
  - Распознавание заметок о ланцете: ключевые слова `ланцет`, `lancet`, `прокалывател`, `игла`, `иглы`, `иглу`, `needle` (с фильтрацией предупреждений и ошибок).
  - Распознавание продления / перезапуска / смены: `продл` (продление, продлен, продлить, продлена), `рестарт`, `restart`, `extend`, `перезапуск`, `смена`, `замена`, `новый`, `start`.
  - Парсинг дней продления (регулярные выражения для `+N`, `на N дней`, `N days`, `restart N`, `продлен на N`).
  - Если дни указаны: обновляем `durationDays` и `lastUsedDurationDays`, сбрасываем дату отсчёта `installedAt = treatment.timestamp`.
  - Если дни не указаны: начинаем новый цикл с текущим `durationDays`, обновляем `installedAt = treatment.timestamp`.

### 5. `strings.xml` / `values-ru/strings.xml`
- Добавление недостающих строковых ресурсов для подсказок фонарика и жестов AoD.

## План верификации
1. Сборка `./gradlew assembleDebug` и юнит-тесты `./gradlew testDebugUnitTest`.
2. Тестирование поворота экрана через adb: `adb shell settings put system user_rotation 1` / `0`.
3. Тестирование двойного тапа фонарика и читаемости подсказок.
4. Проверка корректного обновления сахара и сброса статуса потери связи.
5. Проверка автопродления сенсора через тестовую заметку в treatments.
