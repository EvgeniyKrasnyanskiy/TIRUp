# План комплексной доработки TIRUp

## 1. Исправление темы и контрастности (Dark / Light)
- Заменить хардкод `TextPrimaryDark`, `DarkSurface` на семантические `MaterialTheme.colorScheme` (`surface`, `onSurface`, `onSurfaceVariant`, `outline`, `background`).
- В Светлой теме:
  - Фон экрана: мягкий чистый `0xFFF1F5F9` (Slate 100).
  - Карточки Bento: чисто белые `0xFFFFFFFF` с аккуратным бордером `0xFFE2E8F0`.
  - Текст: тёмно-синий/графитовый `0xFF0F172A` и `0xFF475569`.
  - Диалоговые окна: корректные цвета заголовков и текста.
- В Тёмной теме:
  - Фон: глубокий `0xFF0B0F17`.
  - Карточки: `0xFF161E2E`.
  - Текст: `0xFFF8FAFC` и `0xFF94A3B8`.

## 2. Настройки: нижняя панель
- Удалить кнопку-прямоугольник Telegram, сделать лаконичную ссылку-текст: `Telegram-канал проекта: @diakia`.
- В самый низ списка добавить заметную кнопку **«Назад»** для мгновенного возврата на главный экран без прокрутки.

## 3. Экран Медицинских отчётов
- Вернуть **«🟢 Активное время сенсора»** в самый верх списка параметров карточек отчёта.
- Добавить явный индикатор прогресса (LinearProgressBar / статус в %) при импорте больших файлов.
- Зафиксировать размер пиктограммы удаления (🗑️) `size(24.dp)`.

## 4. Точный расчёт GVI и ночного сна
- В `GlucoseMetricsCalculator`:
  - Если `nightReadingsCount < 6` (менее 30 мин данных в ночное окно), выводить: *«Недостаточно ночных данных»*.
  - Улучшить алгоритм GVI для работы с длинными историческими наборами с учетом разрывов между сенсорами.

## 5. Реорганизация главного экрана (FocusScreen) и экрана Трендов (TrendsScreen)
- **Экран «Суточный профиль»**:
  - Перенести блок «Распределение по диапазонам» на экран Трендов.
  - Добавить на его место информативные карточки:
    - **«Точек за сегодня»** (например: `288 измерений • 100% покрытия`).
    - **«Мин / Макс за сутки»** (например: `Min 4.1 • Max 8.9 ммоль/л`).
  - Исправить полосу прогресса Компенсатора цели: динамически отображать соотношение текущего % к целевому (с учетом переключения TIR / TING).
- **Экран «Аналитика трендов»**:
  - Добавить переключатель `[ TIR 3.9–10.0 | TING 3.9–7.8 ]`.
  - Разместить блок «Распределение по диапазонам».
  - Добавить на суточный AGP график метки часов X (`00:00`..`24:00`) и значения Y (`3.9`, `10.0`, `14.0`).
