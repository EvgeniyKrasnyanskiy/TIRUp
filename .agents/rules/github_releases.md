# GitHub Release Conventions

## Language & Formatting
1. **GitHub Releases in English**:
   - All GitHub release titles and release notes (`gh release create` / `gh release edit`) must strictly be written in English.
   - Do NOT paste raw Russian text from `CHANGELOG.md` into GitHub releases.
   - While `CHANGELOG.md` in the repository can be kept in Russian or bilingual for local documentation, public-facing GitHub Release Notes must always be in clear, professional English.

2. **Release Content Structure**:
   - Welcome banner and high-level summary of the release.
   - Categorized feature highlights with emojis (Added, Fixed, Security, Performance).
   - Clear explanations of technical improvements and user-facing benefits.
   - Standard installation instructions referencing the attached signed APK asset (`TIRUp-v<version>-release.apk`).
